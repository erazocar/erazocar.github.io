HydroApps

A store of hydrology apps, workflows, notebooks and containers that run anywhere

HydroApps (HydroAppStore) is where hydrological work is shared as something you can run, not just read. Listings can be web apps, HydroBlox workflows, Python and R notebooks (Pyodide and WebR), model projects, datasets or containers. They run in the browser or on your own machine, and each listing is versioned.

A tour of the listing types: browsing the store, a Hurricane Helene web app, an HBV + GLUE snowmelt container, a HydroBlox workflow, an R notebook running in the browser with WebR, and a Python notebook running with Pyodide (1.5× speed).
