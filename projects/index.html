Web-native scientific computing

Hydrological analysis usually needs installed software, servers and data wrangling before any science happens. These libraries move that work into the browser: a common analysis layer in HydroLang, CPU/GPU workers and WebAssembly in HydroCompute, and peer-to-peer data transfer in HydroRTC. They are part of HydroSuite, an NSF POSE-supported ecosystem of 20+ open-source web libraries, and HydroApps packages results as apps, notebooks and containers anyone can run.

GPU numerical simulation

Shock-capturing flood solvers usually run as desktop codes or on clusters. FluxCell fuses reconstruction, Riemann fluxes and the update of each time step into a single WebGPU dispatch, and GRADIS builds a complete 2D/3D flood modeling environment on GPU solvers: terrain, forcing, structures and gauges, running in real time on the user's own GPU.

FluxCell

A fused single-dispatch MUSCL-Hancock HLLC scheme for the shallow-water equations on WebGPU

GRADIS

A complete 2D/3D flood modeling environment that runs in the browser

Model evaluation

Agreement between simulations and observations is often reduced to a few skill scores. HyMES adds structural diagnostics, hydrological signatures and MCMC-based uncertainty at each gauge, and HyMES Regional extends the analysis to station networks with kriging, L-moment frequency and trend detection. Both are described in preprints under review at Environmental Modelling & Software, with support from NSF award 2611747.

HyMES

Physics-informed uncertainty and diagnostics for streamflow model evaluation

HyMES Regional

Regional, multi-station analysis of observations and model simulations

AI-assisted research systems

Language models can write and run analyses, but the code behind each result usually lives in one session. HydroBlox makes every workflow step a visible block that can be checked and rerun, with an AI assistant beside the canvas. HydroClaw is a study workspace where language-model agents plan and run hydrological analyses from a library of validated methods.

HydroBlox

AI-assisted visual programming for reproducible hydrology

HydroClaw

Replicable hydrological studies by language-model agents, planned over a typed method graph
