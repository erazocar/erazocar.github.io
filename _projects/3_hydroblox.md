HydroBlox is a node-based canvas for building hydrologic workflows. You drag blocks for data retrieval, analysis, simulation and plotting onto the canvas, wire them into a pipeline, and run it in the browser with native Python, R and JavaScript execution. An integrated AI assistant helps write code and explain results. Because every step of a workflow is visible, anyone can check it and rerun it.
